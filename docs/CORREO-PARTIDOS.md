# Correo a los partidos (borrador)

Se envía a cada partido incluido con sus posiciones codificadas, antes de publicarlas. Destinatario: el correo de prensa o de contacto oficial que figure en la web del partido. Adjunto: la tabla de sus posiciones (afirmación, posición, cita, enlace, fecha), que se genera a partir de `data/`.

Plazo de respuesta: 72 horas. Registra en `docs/contenido/respuestas-partidos.md` la fecha de envío, la respuesta y qué se aceptó o no, con el motivo.
